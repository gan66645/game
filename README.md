# 🎮 Game

两个经典小游戏，纯 HTML 单文件实现，打开即玩。

## 游戏列表

### 🐍 贪吃蛇 (snake.html)

经典贪吃蛇游戏，暗色主题风格。

- **操作**: 方向键 / WASD 控制方向，空格暂停
- **特点**: 吃食物加速、得分系统、最高分本地存储、移动端触摸方向键
- **技术**: Canvas 渲染，20×20 网格

### 🀄 连连看 (lianliankan.html)

清宫国风主题连连看，古典中式美学。

- **操作**: 鼠标点击两张相同的牌即可消除（需存在不超过两个拐角的通路）
- **特点**: 提示功能、洗牌功能、计时计分
- **技术**: Canvas 渲染，古典国风视觉

## 使用方式

直接下载对应的 `.html` 文件，用浏览器打开即可。

```bash
git clone https://github.com/gan66645/game.git
cd game
# 双击 snake.html 或 lianliankan.html
```
